# 01 — SafeLoop

- 단계: 프로토타입 검증
- 한 줄 제안: 차량과 내비게이션 데이터로 출발 준비·주행·도착 정리 습관을 설명하고 다음 이동에서 고칠 행동 하나를 제안하는 전 주기 운전 코치

SafeLoop는 이 포트폴리오 구조를 만들기 전에 개발을 시작했으므로 파일을 이동하지 않는다. 현재 Android 프로젝트 전체와 루트 `docs/`가 SafeLoop의 구현·제안서 산출물이다.

## 구조 이전 원칙

현재 빌드와 문서 링크를 보호하기 위해 제출 완료 전에는 기존 파일을 옮기지 않는다. 향후 필요하면 SafeLoop 전용 저장소로 분리하거나, 이 폴더에 최종 산출물 사본만 정리한다.
